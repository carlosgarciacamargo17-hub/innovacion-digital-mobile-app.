# Guía de contribución
1. Crea un issue con la plantilla de tarea.
2. Rama desde `develop`: `feature/<id>-descripcion`.
3. Commits convencionales: `feat:`, `fix:`, `docs:`, `chore:`.
4. Abre un Pull Request con la plantilla; requiere 1 aprobación.
5. Cumple la Definición de Hecho (`docs/04-tablero-tareas.md`).
